# ADR-0005: Using Nextcloud as Personal Cloud Platform

**Date:** 2026-03-11

## Status: Accepted

## Context

The goal of this project is to build a self-hosted personal cloud system for file storage,synchronization, and remote access.

## Decision

Nextcloud provides a full open-source ecosystem with active development, strong community support, and extensive documentation.

It will run on a self-hosted Debian server using a LAMP stack (Apache, MariaDB, PHP).

## Alternatives Considered

- Owncloud
- Seafile

## Consequencies 

Advantages:

- Open-source
- Large ecosystem of applications
- Web interface and synchronization clients
- Strong Community Support

Disadvantages:

- Requires careful server configuration
- Higher resource usage compared to minimal file servers
